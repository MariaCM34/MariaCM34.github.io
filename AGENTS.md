# AGENTS.md — Portfolio sprint contract

You are building an interview-ready personal engineering portfolio. Work independently only inside the assigned path.

## Non-negotiable

1. No fabricated experience, credentials, certifications, performance gains, client brands, production figures or features.
2. Use fictional businesses, synthetic datasets, and deterministic fixtures. Label synthetic/demo data visibly. Never copy employer/client code, schemas, credentials, logs or internal document excerpts.
3. The deployed site must work as a STATIC website on GitHub Pages; no exposed LLM/API secrets or dependence on a private backend. If optional real AI integration is proposed, document it as future work until deployed securely and validated.
4. The project's default state must be truthful: empty states, failures, validation errors, and explanations must work. No decorative non-functioning buttons.
5. Each project must show (a) business problem, (b) architecture decisions, (c) interactive behavior, (d) observed test results, (e) limitations and reproducibility instructions.
6. Responsive UI, keyboard usability, legible small-screen content, Spanish and English support where feasible.
7. A project is **DONE only when** its acceptance tests pass and it can be used by opening its route via a local HTTP server.
8. Preserve unrelated files, never overwrite the repository root `index.html` unless assigned integration ownership, never use destructive git commands, and never write into another agent's project folder.
9. Run tests yourself and report commands, counts and failing checks. No statements such as 'verified' without evidence.
10. Commit only files under assigned paths on your own branch/worktree. No remote push unless the user approves.

## Required report

```text
Files changed:
Demo URL (local path):
What users can do:
Tests run and actual results:
Limits/unfinished:
Git commit SHA:
```

The coordinator merges work only after checking the acceptance criteria in `SPRINT.md`.
